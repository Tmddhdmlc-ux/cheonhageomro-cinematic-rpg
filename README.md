# 천하검로 v0.9 — 허초와 변초

관절형 전신 애니메이션과 시네마틱 기술 연출 위에 **상대 선택·두 전장·검세 공방·기세·파세·행동 예고·허초/변초 심리전·초식 중 응수·선기 연격**을 결합한 1대1 턴제 무협 RPG 프로토타입입니다.

## 실행

`index.html`을 PC 브라우저에서 바로 열면 됩니다. 외부 서버, 빌드, 패키지 설치가 필요하지 않습니다.

브라우저가 로컬 파일 실행을 제한하는 환경이라면 이 폴더에서 임의의 정적 파일 서버를 실행해도 동일하게 동작합니다.

## 조작

- 마우스: 기술 선택 / 기술 설명 확인
- `1`~`5`: 해당 기술 즉시 사용
- `Q`: 운기조식 — 내력·기세·HP 회복
- `W`: 적 초식의 응수 구간에서 유운보 선택
- `E`: 적 초식의 응수 구간에서 반격세 선택
- `Space`: 적 초식의 응수 구간에서 무대응 선택
- `F1`: 플레이어 HP 전체 회복
- `F2`: 플레이어 내력 전체 회복
- `F3`: 적 HP 전체 회복
- `F4`: 적 AI ON/OFF
- `F5`: 슬로모션 ON/OFF
- `F6`: 적 기세를 10으로 설정
- `F7`: 플레이어 기세를 10으로 설정
- `F8`: 적 다음 초식 강제 변경
- `F9`: 적 파세 연출 강제 테스트
- `R`: 현재 상대 재도전

## v0.8 응수와 선기

- 공격형 적 초식은 타격 직전의 결정 프레임에서 시간 제한 없이 멈춥니다. 이때만 W 유운보, E 반격세, Space 무대응을 선택할 수 있습니다.
- 응수 선택 순간의 기세와 초식 규칙을 스냅샷하므로 프레임 속도나 이후 상태 변화와 무관하게 결과가 결정됩니다.
- 반격세 또는 유운보에 성공하면 `先機` 1스택을 얻으며, 다음 기본검이 확정 2타 연격이 되고 두 번째 타격의 치명타 확률이 20%p 증가합니다.
- 선기가 없을 때 기본검 연격은 중립 25%, 허점 50%, 검세 저항 0%입니다. eligible 기본검이 두 번 연속 연격에 실패하면 다음 eligible 기본검이 확정 연격으로 이어집니다.
- 기본검 버튼과 툴팁에서 현재 연격 확률과 선기·누적·검세 보정 원인을 확인할 수 있습니다.

## v0.9 허초와 변초

- 염라의 살풍세 3/4에는 `흑풍허초`, 무진의 3수째에는 `철산변도`가 배치됩니다. NEXT는 두 후보를 동등하게 보여 주며 결정 전에는 정답을 숨깁니다.
- 적은 허초 예약 시 최근 W/E 응수 2회를 읽어 갈래를 확정합니다. 같은 응수를 두 번 반복하면 그 습관을 깨는 변초를 고르고, 기록이 부족하거나 섞였으면 두 갈래를 결정적으로 교대합니다.
- 공통 준비 자세에서 발·골반·어깨·무기 각도가 실제 변초 자세로 바뀐 뒤 0.1초 정적을 거쳐 무제한 응수 창이 열립니다. Space는 습관 기록에 남지 않습니다.
- 허문세와 잠도세를 향한 선행 공격은 모두 중립입니다. 결정 후에는 실제 초식·검세·응수 힌트와 후보 강조가 함께 갱신됩니다.
- 정답 응수는 `간파 — 변초를 꺾었다`와 선기를 주고, 오답은 `읽혔다 — 변초에 걸렸다`로 표시됩니다.

## 구현 구조

- `js/skills.js`: 다섯 기술과 기본검 조건부 2타 연격의 타임라인
- `js/enemy-defense.js`: 받아내기·흘리기·보법 이탈 반응과 상태 복귀
- `js/mujin.js`: 철산도객 무진의 3수 주기·압박 순환·조식 우선 삽입과 허초 보존 AI
- `js/defense.js`: 초식 중 응수 구간, 허초 결정 자세, 변초별 파훼 판정과 적 전용 타임라인
- `js/effects.js`: 검광, 충격파, 잔상, 꽃잎, 번개, 피해 숫자
- `js/camera.js`: 줌, 팬, 팔로우, 흔들림, 복귀
- `js/audio.js`: Web Audio 기반 임시 효과음
- `js/data.js`: 캐릭터와 기술 데이터
- `js/main.js`: 캔버스 렌더링, 입력, HUD 연결

## v0.7 비무 흐름

- 첫 화면의 `비무첩`에서 마우스 또는 ←/→와 Enter로 상대를 고릅니다.
- `흑풍검 염라`는 기존 월하 산정에서 쾌검·변칙·살풍세 2페이즈를 사용합니다.
- `철산도객 무진`은 청석관문에서 낮은 중심과 중도로 기세를 압박하며 `철산횡도 → 낙봉개산 → 철벽진`을 반복합니다.
- 무진의 기세가 35 미만이면 `철산가세`가 한 번 삽입되어 기세 28을 회복하고 중단했던 순서로 돌아갑니다. 플레이어 기세가 40 미만인 다음 주기는 철벽진부터 시작합니다.
- 철산횡도는 기세 65 이상의 반격세, 낙봉개산은 유운보, 철벽진은 기세 45 이상의 반격세로 확정 대응합니다.
- 승패 후 `재도전`으로 같은 비무를 다시 시작하거나 `상대 선택`으로 비무첩에 돌아갈 수 있으며, R은 현재 상대 재도전입니다.

## 공통 전투 규칙

- 적 상태창 아래의 `NEXT · 다음 초식`을 확인합니다.
- NEXT의 `검세 · 허점`과 상대의 전신 자세를 읽고, `베기`·`찌르기`·`연격` 중 `유효` 표시된 무공으로 공격하면 HP 피해 10%, 기세 피해 50% 보너스를 받습니다.
- `막힘`·`흘림`·`보법` 표시된 공격은 상대의 검세 방어에 걸려 HP 피해가 60%, 기세 피해가 50%로 감쇄되고 서로 다른 전신 반응이 발생합니다.
- 횡봉세는 베기를 받아내고, 직침세는 찌르기를 흘리며, 유영세는 베기와 찌르기의 공격선을 보법으로 벗어납니다.
- 사기조식은 모든 일반 공격에 열리고, 흑천낙검의 절기축세는 일반 공격의 기세 피해만 강화합니다. 오의는 항상 중립입니다.
- `SLASH`에는 반격세, `THRUST`에는 유운보가 특히 강합니다.
- 기술로 상대의 `氣勢`를 0까지 낮추면 `破勢 / BREAK`가 발생하며 추가 행동을 얻습니다.
- 파세된 적은 방어력이 35% 감소하고 다음 플레이어 기술의 피해를 30% 더 받습니다.
- 파세 상태에서 천뢰파천검을 사용하면 감속·지연 피해 숫자·강화된 낙뢰가 포함된 마무리 연출이 발동합니다.
- 염라의 HP가 50% 이하가 되면 추가 행동을 보장한 뒤 `2식 · 살풍세`로 전환합니다.
- 살풍세는 반격세와 유운보 사용 습관에 따라 고정된 4수 노선을 선택하며, NEXT 패널에 현재 위치를 표시합니다.
- 4/4 `흑천낙검` 예고 중 염라의 기세를 0으로 만들면 `破絶 / 절기 파훼` 후 새 주기로 이어집니다.
